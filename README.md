# MSE 800 — Professional Software Engineering

A small workspace containing class activities and example scripts for MSE 800.

## Project Structure

- Week 1
	- [Week 1/helloworld.py](Week%201/helloworld.py) — simple "Hello, world" example
	- [Week 1/activity_3.py](Week%201/activity_3.py) — Fibonacci series example
	- [Week 1/BMI_calculator.py](Week%201/BMI_calculator.py) — BMI calculator (function-based)
- Week 2
	- [Week 2/bmi_calculator.py](Week%202/bmi_calculator.py) — BMI calculator (OOP version)
	- [Week 2/bmi_edwards.py](Week%202/bmi_edwards.py) — Edwards' BMI variant
	- [Week 2/Word_G.py](Week%202/Word_G.py) — word/greeting utilities

## Usage

Run any script with Python 3. Example:

`python3 "Week 1/helloworld.py"`

To run a different file, replace the path above with the target script.
